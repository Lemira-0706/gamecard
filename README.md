# 🎭 RPG世界观 · 沉浸式角色扮演工作台

> 一个基于单文件 HTML 的沉浸式角色扮演/AI对话应用，参考 Chatbox 架构 + 微信对话风格。

## ✨ 功能特性

### 🌍 世界管理
- **世界观设定**（必填）：整个游玩的背景规则
- **位面系统**（可选）：给宿主下发任务、传达信息的存在
- **故事线**（必填）：整个故事的重要走向
- **角色卡片**：
  - 🧑‍🚀 宿主/玩家（必填）
  - 💖 目标对象（可选）
  - 🎭 配角（可选）
  - 🤖 NPC（可选）

### 💬 对话系统
- 微信风格气泡聊天界面
- 支持 Markdown 渲染
- 消息操作：删除 / 重新生成 / 修改
- Token 消耗统计
- 支持图片上传
- 自动构建 System Prompt（基于世界设定）

### 🔌 API 支持
内置 9 大厂商：
- OpenAI (GPT-4o / GPT-4o-mini)
- Anthropic (Claude 3.5 Sonnet)
- Google (Gemini)
- DeepSeek
- 智谱AI (GLM)
- 通义千问 (Qwen)
- Moonshot (Kimi)
- 豆包 (火山引擎)
- 自定义兼容 API

| 🌸 朝暮浅紫 | 浪漫梦幻 |

### 📦 数据管理
- 一键导出/导入 JSON
- 数据存储在 localStorage（纯本地，无服务器）
- API Key 仅保存在浏览器本地

## 🚀 使用方式

1. 直接用浏览器打开 `index.html`
2. 点击左侧「创作新世界」创建角色扮演世界
3. 在「API配置」中填入你的 API Key
4. 选择模型，开始对话！

## ⚠️ 注意事项
- API Key 仅存储在本地浏览器 localStorage 中，不会上传任何服务器
- 如需在线部署，请确保使用 HTTPS 以保护 Key 安全
- 图片/头像上传为 base64 编码，存储于本地
